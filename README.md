# 🌫️ PM2.5 Dashboard

แดชบอร์ดแสดงค่าฝุ่น PM2.5 ของ 8 เมืองในประเทศไทย พร้อมแผนที่ กราฟ และฐานข้อมูลเก็บประวัติ ส่งออกรายงานเป็น PDF และ CSV ได้

## ฟีเจอร์

- การ์ดสีแสดงระดับ PM2.5 ของแต่ละเมือง
- แผนที่ (Leaflet) พร้อมหมุดสีและ popup
- กราฟเส้นย้อนหลัง 24 ชั่วโมง และกราฟแท่งค่าเฉลี่ยรายวัน 7 วัน (Chart.js)
- เก็บข้อมูลลง SQLite ทุกชั่วโมงโดยอัตโนมัติ และลบข้อมูลเก่ากว่า 30 วัน
- ดาวน์โหลดรายงานเป็น PDF (ภาษาไทย) และ CSV
- แคชข้อมูลจาก API 10 นาที ลดการเรียกซ้ำ
- ใช้ `Promise.allSettled` ถ้าบางเมืองดึงข้อมูลไม่ได้ ระบบยังทำงานต่อ

## เทคโนโลยี

Node.js, Express, SQLite (better-sqlite3), PDFKit, JavaScript, Leaflet, Chart.js, Open-Meteo Air Quality API

## วิธีรัน

ต้องติดตั้ง Node.js เวอร์ชัน 18 ขึ้นไป

```bash
git clone https://github.com/go123456mm-alt/pm25-dashboard.git
cd pm25-dashboard
npm install
node server.js
```

เปิด http://localhost:3000

## โครงสร้างโปรเจกต์

```
server.js        Backend (Express, SQLite, API, PDF/CSV)
public/          หน้าเว็บ (HTML, CSS, JavaScript)
fonts/           ฟอนต์ภาษาไทยสำหรับ PDF (Sarabun)
air.db           ฐานข้อมูล SQLite (สร้างอัตโนมัติ ไม่อยู่ใน Git)
```

## API

| Endpoint | หน้าที่ |
|---|---|
| `GET /api/air` | ค่าปัจจุบันของทุกเมือง |
| `GET /api/history/:city` | ย้อนหลัง 24 ชั่วโมง จากฐานข้อมูล |
| `GET /api/daily/:city` | ค่าเฉลี่ย/สูงสุด/ต่ำสุดรายวัน 7 วัน |
| `GET /api/csv/:city` | ดาวน์โหลด CSV ย้อนหลัง 7 วัน |
| `GET /api/report/:city` | ดาวน์โหลดรายงาน PDF |

## การตัดสินใจออกแบบ

- **เรียก API ผ่าน backend** เพื่อทำแคชและเก็บข้อมูลลงฐานข้อมูลของตัวเอง
- **SQLite** เป็นไฟล์เดียว ไม่ต้องติดตั้งฐานข้อมูลแยก เหมาะกับโปรเจกต์ขนาดนี้
- **คีย์หลัก (city, time)** กันข้อมูลซ้ำ และใช้ `INSERT OR REPLACE` อัปเดตค่าล่าสุด
- ใช้ parameterized query (`?`) ในทุกคำสั่ง SQL

## ข้อจำกัด

- ข้อมูลจาก Open-Meteo เป็นค่าจากโมเดลคาดการณ์ ไม่ใช่เครื่องวัดจริง อาจต่างจากสถานีตรวจวัด เช่น Air4Thai
- เก็บประวัติย้อนหลังสูงสุด 30 วัน
